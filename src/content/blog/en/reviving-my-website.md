My personal website has been offline for a while. The previous version (2020) was built with **Nuxt 2**, **Vuetify** and **Firebase**, and before that I had a hand-made site from 2016–2019.

This time I wanted something simpler:

- **Static HTML**: no server, no database. Pages are pre-rendered at build time.
- **Markdown posts**: writing a new entry is just adding a `.md` file.
- **Bilingual**: every page exists in English and Spanish.
- **Open source**: the code lives publicly on [GitHub](https://github.com/EddyArellanes/EddyArellanes.github.io).

## The stack

- [Astro](https://astro.build) with content collections for the blog
- [Tailwind CSS](https://tailwindcss.com) with the typography plugin
- GitHub Actions + GitHub Pages for deployment

I'll be sharing more of my side projects in public, mainly **utilities and games**, and writing about what I learn along the way. Stay tuned!
