Mi sitio web personal estuvo fuera de línea por un buen tiempo. La versión anterior (2020) estaba hecha con **Nuxt 2**, **Vuetify** y **Firebase**, y antes de eso tuve un sitio hecho a mano entre 2016 y 2019.

Esta vez quería algo más simple:

- **HTML estático**: sin servidor ni base de datos. Las páginas se generan al compilar.
- **Entradas en Markdown**: escribir una nueva entrada es solo agregar un archivo `.md`.
- **Bilingüe**: cada página existe en inglés y en español.
- **Open source**: el código vive de forma pública en [GitHub](https://github.com/EddyArellanes/EddyArellanes.github.io).

## El stack

- [Astro](https://astro.build) con content collections para el blog
- [Tailwind CSS](https://tailwindcss.com) con el plugin de tipografía
- GitHub Actions + GitHub Pages para el despliegue
